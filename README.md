# 棋紀高手

可在瀏覽器直接下的中國象棋，附暗棋。雙擊 `啟動.bat`，它會用 Chrome 或 Edge 打開。不必安裝。

畫面上的標題是棋紀高手。資料夾沿用橘中局，典故來自唐人筆記裡的橘中對弈，也是明代棋譜《橘中秘》。棋盤河界仍寫傳統的「楚河」「漢界」，那是棋盤上的字，不是標題。

## 怎麼下

- **象棋**：點自己的棋子，再點亮起的位置。拖曳空白處轉動，滾輪拉近。吃子時棋子會被擊碎，炮會開火。
- **暗棋**：點蓋住的子是翻棋；翻過以後點自己的子，再點鄰格或砲的目標。
- **人機**有入門、進階、高手。高手會多算吃子，開局不會白送砲去換馬。
- **雙人同機**輪流下。象棋可選執紅或執黑。
- **悔棋**在人機時會連電腦的應著一起收回。
- **提示**給目前行棋方一著。
- **繼續上一盤**讀瀏覽器裡的進度。新對局在走出第一步之後才覆寫舊檔。

## 規則摘要

象棋含九宮、過河、蹩馬腿、塞象眼、砲架、將帥不可照面、將死、困斃。同一局面第三次出現時，若只有一方每步都在將軍，那一方因長將判負，否則和棋。六十回合沒有吃子也和棋。

暗棋吃子順序是將大於士、象、車、馬、砲、兵。馬不能吃士。兵可吃將，將不吃兵。砲要隔一子才能吃。五十步沒有吃子和棋。

瀏覽器開的是打包後的 `js/play.js`，這樣直接雙擊檔案也能下。改了 `js` 裡的模組之後，在專案資料夾執行：

```bash
npx esbuild js/main.js --bundle --format=iife --outfile=js/play.js
```

## 測試

```bash
node tools/selftest.mjs
```
